Nomad Visa Finder

This finder introduces a searchable list of destinations that offer remote-work visas. The initial release prioritizes clarity so travellers can quickly evaluate if an opportunity fits their situation.

MVP Notes

  • Inputs: nationality, desired region, income threshold, and documentation readiness.
  • Outputs: visa summary cards showing eligibility, costs, processing timelines, and renewal notes.
  • Data sources: curated visa dataset maintained in the repository with manual updates.

Future iterations will add bookmarking and save-for-later features, but the MVP focuses on surfacing accurate information first.
