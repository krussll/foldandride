Goal

The Travel Carbon Offset Calculator estimates the climate impact of common travel plans. It simplifies CO₂e math and pairs the totals with curated offset ideas that align with Fold & Ride's sustainability mission.

Inputs

  • Transport mode (flight, train, bus, car, ferry)
  • Distance or route lookup via airport and station codes
  • Cabin class or vehicle efficiency profile
  • Trip frequency or number of travellers
  • Accommodation type with nightly counts

Outputs

  • Total emissions in kilograms of CO₂e
  • Category breakdown (transport vs. stay)
  • Suggested offsets with estimated project cost
  • Tips for reduction before offsetting
  • Downloadable summary for personal reporting

Data & Methodology

Calculations reference Atmosfair and internal conversion tables. MVP copy explains assumptions clearly so travellers know how numbers were produced before we automate the API calls.
