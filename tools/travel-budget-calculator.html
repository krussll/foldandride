Travel Budget Calculator

This page outlines the target flow for a calculator that estimates overall trip costs. The MVP will accept location, trip length, traveller count, and lifestyle inputs before returning a line-item breakdown.

MVP Notes

  • Inputs: destination, currency preference, trip duration, accommodation style.
  • Outputs: lodging, food, transport, workspace, and buffer estimates.
  • Data sources: exchangerate.host and baseline cost tables maintained in the project repository.

Engineers can use this scaffold to connect the Google Cloud Function once real data endpoints are ready.
